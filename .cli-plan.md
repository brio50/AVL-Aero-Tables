# CLI Redesign Plan — YAML-driven sweep interface

## Goal

Replace the thin `avl-aero-tables run <command_file>` CLI with a YAML-driven sweep
interface where each aircraft example has a `<name>.yml` alongside its `.avl` file.
The yml becomes the project file — the single entry point for sweep, geometry plot,
and aero plot. This is also the foundation for a future GUI ("File → Open").

---

## New CLI surface

```
avl-aero-tables verify
avl-aero-tables sweep  examples/bd/bd.yml
avl-aero-tables plot geometry examples/bd/bd.yml
avl-aero-tables plot aero     examples/bd/bd.yml
```

- `verify` — unchanged, keep as-is
- `sweep` — load yml, resolve paths, run AVL sweep
- `plot geometry` — four-view geometry plot from the .avl file (no sweep needed)
- `plot aero` — 3-D aero coefficient surfaces from the latest sweep results
- `run <command_file>` — **remove entirely** (was never the intended interface)

---

## YAML schema

```yaml
avl_file: bd.avl          # required; relative to yml file's directory
mass_file: bd.mass        # optional; relative to yml file's directory

alpha: [-5, 0, 5, 10, 15]  # required; degrees
beta: [0]                   # required; degrees

ctrl_sweeps:               # optional; omit for alpha/beta-only sweep
  elevator: [-10, -5, 0, 5, 10]
  rudder:   [-10, 0, 10]
  aileron:  [-10, 0, 10]

out_format: csv            # optional; csv | json | df — default csv
```

**`out_dir` is never in the yml.** It is always derived at runtime:

```
<yml_dir>/../runs/<stem>/<YYYY-MM-DD-HHMMSS>/
```

So `examples/bd/bd.yml` → `examples/runs/bd/2026-05-15-120000/`.

Each sweep call creates a fresh timestamped subdir. `plot aero` auto-discovers
the most recent subdir under `<yml_dir>/../runs/<stem>/`. This convention is
intentional for GUI support — a future GUI lists all runs in that directory as
a run-history panel.

## Files to create / modify

### `examples/bd/bd.yml` — **new**

Canonical example yml for the Bubble Dancer aircraft. Use this schema:

```yaml
avl_file: bd.avl
mass_file: bd.mass

alpha: [-5, 0, 5, 10, 15]
beta: [0]

ctrl_sweeps:
  elevator: [-10, -5, 0, 5, 10]
  rudder:   [-10, 0, 10]
  aileron:  [-10, 0, 10]

out_format: csv
```

bd.avl has three control surfaces: `elevator`, `rudder`, `aileron` (verified from
`grep CONTROL examples/bd/bd.avl`).

### `avl_aero_tables/avl_cli.py` — **rewrite**

Current file is ~70 lines with `verify` and `run` subcommands. Replace with:

```
_build_parser()
  ├── verify
  ├── sweep  <yml>
  └── plot
        ├── geometry  <yml>
        └── aero      <yml>

main(argv)
  ├── verify  → avl_bin.verify()
  ├── sweep   → _cmd_sweep(args)
  └── plot    → _cmd_plot_geometry(args) or _cmd_plot_aero(args)
```

**`_cmd_sweep(args)`:**
1. Load and parse yml (`yaml.safe_load`)
2. Validate required keys: `avl_file`, `alpha`, `beta`
3. Resolve `avl_file` and `mass_file` relative to `yml.parent`
4. Compute `out_dir = yml.parent.parent / "runs" / yml.stem / datetime.now().strftime(...)`
5. Call `avl_sweep.run(avl_file, alpha, beta, ctrl_sweeps, out_dir, out_format, mass_file)`

**`_cmd_plot_geometry(args)`:**
1. Load yml, resolve `avl_file`
2. `geometry = avl_fileread(avl_file)`
3. `fig = avl_fileplot(geometry)`
4. `plt.show()`

**`_cmd_plot_aero(args)`:**
1. Load yml, compute base dir `yml.parent.parent / "runs" / yml.stem`
2. Find all timestamped subdirs matching `YYYY-MM-DD-HHMMSS` pattern; pick latest
3. Error clearly if none: `"No sweep results found. Run 'avl-aero-tables sweep <yml>' first."`
4. `results = st_fileread(latest_dir)`
5. Build `AeroDatabase` — see `aero_filewrite.py` for the constructor/function
6. `figs = aero_fileplot(aero)`
7. `plt.show()`

## Key constraints / context

- `avl_sweep.run()` already accepts an explicit `out_dir` — pass it from the CLI.
  Do **not** change `avl_sweep.run()` signature or default behavior.
- The sweep engine's internal default (`out/<name>/<timestamp>/` relative to cwd)
  is intentionally bypassed when the CLI calls it with an explicit `out_dir`.
- All AVL-facing filenames must stay under ~80 chars (Fortran string limit).
  The staging-in-/tmp mechanism in `avl_sweep.run()` handles this already.
- The installed package entry point is already wired:
  `pyproject.toml` → `avl-aero-tables = "avl_aero_tables.avl_cli:main"`
